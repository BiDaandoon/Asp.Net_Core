
## **مشخصات زبان مشترک (CLS) در چارچوب .NET**

در این مقاله، قصد دارم در مورد **مشخصات زبان مشترک (CLS) در چارچوب .NET** بحث کنم. مشخصات زبان مشترک در چارچوب .NET نیز CLS نامیده می‌شود. لطفاً مقاله قبلی ما را که در آن در مورد سیستم نوع مشترک (CTS) در چارچوب .NET بحث کردیم، بخوانید. در پایان این مقاله، شما خواهید فهمید که مشخصات زبان مشترک (CLS) چیست و چگونه CLS در چارچوب .NET کار می‌کند.

##### **مشخصات زبان مشترک (CLS) در چارچوب .NET چیست؟**

CLS (مشخصات زبان مشترک) بخشی از CLR در چارچوب .NET است. چارچوب .NET از بسیاری از زبان‌های برنامه‌نویسی مانند C#، VB.NET، J#، F# و غیره پشتیبانی می‌کند. هر زبان برنامه‌نویسی قوانین نحوی خاص خود را برای نوشتن کد دارد که به عنوان مشخصات زبان شناخته می‌شود. قوانین نحوی یک زبان برنامه‌نویسی (مشخصات زبان) توسط زبان‌های برنامه‌نویسی دیگر قابل درک نیست. اما، ممکن است موقعیت‌هایی وجود داشته باشد که نیاز به برقراری ارتباط بین دو زبان برنامه‌نویسی مختلف داشته باشیم. برای اطمینان از ارتباط روان بین زبان‌های برنامه‌نویسی مختلف پشتیبانی شده توسط .NET، مهمترین چیز این است که آنها باید مشخصات زبان مشترک داشته باشند که تضمین می‌کند مشخصات زبان تعریف شده در دو زبان مختلف در یک مشخصات زبان مشترک کامپایل شوند.

CLR در چارچوب .NET تمام کدهای زبان‌های برنامه‌نویسی را اجرا می‌کند. این امر به این دلیل امکان‌پذیر است که CLR مشخصات زبانی (قوانین نحوی) خاص خود را دارد که برای همه زبان‌های برنامه‌نویسی پشتیبانی‌شده توسط .NET مشترک است. در زمان کامپایل، هر کامپایلر زبان باید از این مشخصات زبانی CLR پیروی کند و کد MSIL را تولید کند. این مشخصات زبانی CLR برای همه زبان‌های برنامه‌نویسی مشترک است و به عنوان مشخصات زبانی مشترک (CLS) شناخته می‌شود.

برای درک این مفهوم، کاری که اینجا انجام خواهیم داد این است که مشخصات زبان رایج را نقض می‌کنیم و سپس خواهیم دید چه اتفاقی می‌افتد.

##### **مثالی برای درک CLS در چارچوب .NET:**

همانطور که می‌دانیم C# یک زبان حساس به حروف بزرگ و کوچک است در حالی که VB یک زبان حساس به حروف بزرگ و کوچک نیست. این بدان معناست که در C# می‌توانید نام یک عضو را چندین بار با تفاوت حروف کوچک و بزرگ تعریف کنید، اما در VB این امکان وجود ندارد. بنابراین، بیایید دو پروژه کتابخانه کلاس ایجاد کنیم. یکی از زبان C# و دیگری از زبان برنامه‌نویسی VB استفاده می‌کند. سپس سعی خواهیم کرد پروژه کتابخانه کلاس C# را در پروژه کتابخانه کلاس VB استفاده کنیم.

##### **ایجاد پروژه کتابخانه کلاس سی شارپ:**

یک پروژه کتابخانه کلاس با نام **CsharpClassLibrary** با استفاده از زبان برنامه‌نویسی سی‌شارپ ایجاد کنید. پس از ایجاد پروژه کتابخانه کلاس سی‌شارپ، یک فایل کلاس با نام **Calculator.cs** اضافه کنید و سپس کد زیر را در آن کپی و جایگذاری کنید. همانطور که می‌بینید، ما دو متد با نام یکسان اما با تفاوت‌های حروف کوچک و بزرگ ایجاد کرده‌ایم. یکی از متدها با حرف بزرگ C و دیگری با حرف کوچک C شروع می‌شود.

```csharp
namespace CsharpClassLibrary
{
    public class Calculator
    {
        public int Calculate()
        {
            int a = 10, b = 20;
            int c = a + b;
            return c;
        }

        public int calculate()
        {
            int a = 10, b = 20;
            int c = a + b;
            return c;
        }
    }
}
```

##### **ایجاد پروژه کتابخانه کلاس VB:**

به همان راه‌حل CsharpClassLibrary، اجازه دهید یک پروژه کتابخانه کلاس دیگر با نام VBClassLibrary اضافه کنیم، اما از VB به عنوان زبان برنامه‌نویسی استفاده کنیم. در اینجا، در این پروژه می‌خواهیم از پروژه کتابخانه کلاس C# استفاده کنیم، بنابراین ابتدا یک ارجاع به **پروژه CsharpClassLibrary** اضافه می‌کنیم. سپس یک کلاس با نام TestClass.cs ایجاد می‌کنیم و کد زیر را در آن کپی و پیست می‌کنیم.

```vb
Imports CsharpClassLibrary

Public Class TestClass
    Public Sub TestMethod()
        Dim obj As New Calculator()
        obj.Calculate()
    End Sub
End Class
```

حالا، وقتی سعی می‌کنید پروژه کتابخانه کلاس VB را بسازید، خطای زیر را دریافت خواهید کرد. دلیل این امر این است که VB به حروف کوچک و بزرگ حساس نیست و دو متد با نام یکسان پیدا کرده است. این بدان معناست که ما در کد C#، مشخصات زبان مشترک را نقض می‌کنیم.

**عبارت «Calculate» مبهم است زیرا چندین نوع عضو با این نام در کلاس «Calculator» وجود دارد.**

نشان داده شده است، نام متد دوم را به Calculate2 تغییر می‌دهیم **حالا، همانطور که در فایل کلاس Calculator.cs** از **پروژه CsharpClassLibrary** .

```csharp
namespace CsharpClassLibrary
{
    public class Calculator
    {
        public int Calculate()
        {
            int a = 10, b = 20;
            int c = a + b;
            return c;
        }

        public int Calculate2()
        {
            int a = 10, b = 20;
            int c = a + b;
            return c;
        }
    }
}
```

با اعمال تغییرات فوق، اکنون پروژه کتابخانه کلاس VB را بسازید و ساخت آن باید طبق انتظار موفقیت‌آمیز باشد. حال، ممکن است یک سوال داشته باشید، چگونه می‌توان بررسی کرد که آیا کد در چارچوب .NET با CLS سازگار است یا خیر؟

##### **چگونه بررسی کنیم که آیا کد در چارچوب .NET با CLS سازگار است یا خیر؟**

برای بررسی اینکه آیا کد شما از مشخصات زبان مشترک در چارچوب .NET پیروی می‌کند یا خیر، ابتدا باید CLS Compliant را در **فایل AssemblyInfo.cs** فعال کنید . بنابراین، به پروژه کتابخانه کلاس C# یعنی **پروژه CsharpClassLibrary** بروید و **فایل AssemblyInfo.cs** قرار دارد **را که در پوشه Properties** باز کنید . پس از باز کردن **فایل کلاس AssemblyInfo.cs** ، دو مرحله زیر را دنبال کنید.

**مرحله ۱: فضای نام System را به صورت زیر وارد کنید**  
**using System;**

**مرحله ۲: ویژگی CLSCompliant زیر را در انتهای این فایل اضافه کنید و مقدار آن را روی true تنظیم کنید.**  
**[assembly: CLSCompliant(true)]**

با اعمال تغییرات فوق در **فایل AssemblyInfo.cs** ، اکنون فایل کلاس Calculator.cs از پروژه CsharpClassLibrary را مطابق شکل زیر تغییر دهید.

```csharp
using System;
[assembly: CLSCompliant(true)]
namespace CsharpClassLibrary
{
    public class Calculator
    {
        public int Calculate()
        {
            int a = 10, b = 20;
            int c = a + b;
            return c;
        }

        public int calculate()
        {
            int a = 10, b = 20;
            int c = a + b;
            return c;
        }
    }
}
```

حالا، وقتی پروژه کتابخانه کلاس C# را می‌سازید، هشدار زیر را دریافت خواهید کرد.

اگر فایل کلاس AssemblyInfo.cs را طوری تغییر دهید که CLSCompliant را فعال کند، این قابلیت برای همه کلاس‌های درون پروژه ما قابل استفاده خواهد بود. اما اگر می‌خواهید CLSCompliant را در کلاس‌های خاصی فعال کنید، می‌توانید از ویژگی CLSCompliant استفاده کنید. برای مثال، می‌توانید کلاس Calculator را مانند زیر تزئین کنید تا CLSCompliant فقط برای کلاس Calculator فعال شود.

```csharp
using System;

namespace CsharpClassLibrary
{
    [CLSCompliant(true)]
    public class Calculator
    {
        public int Calculate()
        {
            int a = 10, b = 20;
            int c = a + b;
            return c;
        }

        public int calculate()
        {
            int a = 10, b = 20;
            int c = a + b;
            return c;
        }
    }
}
```

حالا، می‌توانید ببینید که متد calculate (که با c کوچک شروع می‌شود) یک هشدار می‌دهد و می‌گوید که مطابق تصویر زیر، با CLS سازگار نیست.

**نکته:** CLS (مشخصات زبان مشترک) در چارچوب .NET مجموعه‌ای از قوانین و محدودیت‌هایی را تعریف می‌کند که هر زبانی که تحت چارچوب .NET اجرا می‌شود، باید از آنها پیروی کند. زبان‌هایی که از مشخصات CLS پیروی می‌کنند، مطابق با CLS نامیده می‌شوند. به عبارت ساده، می‌توان گفت که CLS در چارچوب .NET امکان ادغام یا قابلیت همکاری بین زبانی را فراهم می‌کند.
