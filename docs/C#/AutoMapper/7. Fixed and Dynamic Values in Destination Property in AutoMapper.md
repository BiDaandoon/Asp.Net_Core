
## **نحوه ذخیره مقادیر ثابت و پویا در ویژگی مقصد در AutoMapper**

در این مقاله، قصد دارم نحوه ذخیره مقادیر ثابت و پویا در Destination Property در AutoMapper را با مثال‌هایی با استفاده از زبان C# بررسی کنم. لطفاً مقاله قبلی ما را که در آن متد نادیده گرفتن AutoMapper در C# با مثال‌هایی مورد بحث قرار دادیم، مطالعه کنید.

##### **نحوه ذخیره مقادیر ثابت و پویا در ویژگی مقصد در AutoMapper**

متد AutoMapper UseValue() برای اختصاص یک مقدار ثابت به یک ویژگی مقصد استفاده می‌شود در حالی که ResolveUsing() برای اختصاص یک مقدار پویا به یک ویژگی مقصد در زمان اجرا استفاده می‌شود. اما، از AutoMapper 8.0، متدهای UseValue() و ResolveUsing() منسوخ شده‌اند و اگر سعی در استفاده از دو متد فوق داشته باشید، با خطای زمان کامپایل مواجه خواهید شد. بنابراین، هر آنچه که با استفاده از متدهای UseValue() و ResolveUsing() به دست می‌آوریم، اکنون می‌توانیم با استفاده از متد AutoMapper MapFrom() نیز به همان دست یابیم.

بگذارید این موضوع را با یک مثال درک کنیم. برای درک نحوه اختصاص مقادیر ثابت و پویا به ویژگی‌های مقصد با استفاده از AutoMapper، از دو کلاس زیر استفاده خواهیم کرد. یک فایل کلاس با نام PermanentAddress.cs ایجاد کنید و سپس کد زیر را در آن کپی و جایگذاری کنید. این یک کلاس ساده است که چهار ویژگی دارد.

```csharp
using System;

namespace AutoMapperDemo
{
    public class PermanentAddress
    {
        public string Name { get; set; }
        public string Address { get; set; }
        public string CreatedBy { get; set; }
        public DateTime? CreatedOn { get; set; }
    }
}
```

سپس، یک فایل کلاس دیگر با نام TemporaryAddress.cs ایجاد کنید و سپس کد زیر را در آن کپی و جایگذاری کنید. این یک کلاس بسیار ساده است که چهار ویژگی دارد.

```csharp
using System;

namespace AutoMapperDemo
{
    public class TemporaryAddress
    {
        public string Name { get; set; }
        public string Address { get; set; }
        public string CreatedBy { get; set; }
        public DateTime? CreatedOn { get; set; }
    }
}
```

##### **الزامات کسب و کار:**

الزام کاری ما این است که شیء Source PermanentAddress را به شیء Destination TemporaryAddress نگاشت کنیم. اما نمی‌خواهیم مقادیر ویژگی‌های CreatedBy و CreatedOn شیء Source را به شیء Destination نگاشت کنیم. در عوض، می‌خواهیم مقدار ثابت یا hard-coded شده‌ی "System" را به عنوان مقدار برای ستون CreatedBy و مقدار DateTime فعلی را به عنوان مقدار از ویژگی مقصد CreatedOn ذخیره کنیم. قبل از AutoMapper 8.0، از متدهای UseValue و ResolveUsing استفاده می‌کردیم. اما اکنون باید از متد MapFrom برای اختصاص مقادیر ثابت و پویا به ویژگی مقصد استفاده کنیم.

بنابراین، یک فایل کلاس با نام MapperConfig.cs ایجاد کنید و سپس کد زیر را در آن کپی و جایگذاری کنید. همانطور که می‌بینید، کلاس زیر شامل دو متد یعنی InitializeAutomapper و GetCurrentDateTime است. در متد InitializeAutomapper، ما پیکربندی نگاشت را ارائه می‌دهیم و از متد GetCurrentDateTime برای بازگرداندن زمان داده‌های فعلی سیستم استفاده می‌شود. علاوه بر این، می‌توانید متوجه شوید که با استفاده از متدهای ForMember و MapFrom، مقدار ثابت و hard0-coded System را به ویژگی مقصد CreatedBy اختصاص می‌دهیم و مقدار پویا را از ویژگی مقصد CreatedOn اختصاص می‌دهیم. در متد MapFrom، ما متد GetCurrentDateTime را فراخوانی می‌کنیم و هر مقدار پویایی که متد GetCurrentDateTime برمی‌گرداند را به متد CreatedOn اختصاص می‌دهیم.

```csharp
using AutoMapper;
using System;

namespace AutoMapperDemo
{
    public class MapperConfig
    {
        public static IMapper InitializeAutomapper()
        {
            // Configuring AutoMapper
            var config = new MapperConfiguration(cfg =>
            {
                cfg.CreateMap<PermanentAddress, TemporaryAddress>()
                    // Using MapFrom Method to Store Static or Hard-Coded Value in a Destination Property
                    .ForMember(dest => dest.CreatedBy, act => act.MapFrom(src => "System"))

                    // Before AutoMapper 8.0, to Store Static Value use the UseValue() method
                    // .ForMember(dest => dest.CreatedBy, act => act.UseValue("System"))

                    // Using MapFrom Method to Store Dynamic Value in a Destination Property
                    // Here, we are calling GetCurrentDateTime method which will return a dynamic value
                    .ForMember(dest => dest.CreatedOn, opt => opt.MapFrom(src => GetCurrentDateTime()))

                    // // Before AutoMapper 8.0, To Store Dynamic value use ResolveUsing() method
                    // .ForMember(dest => dest.CreatedBy, act => act.ResolveUsing(src =>
                    // {
                    //     return DateTime.Now;
                    // }))

                    .ReverseMap();
            });

            // Creating the Mapper Instance
            var mapper = config.CreateMapper();

            // returning the Mapper Instance
            return mapper;
        }

        // Method to return Dynamic Value
        public static DateTime GetCurrentDateTime()
        {
            // Write the Logic to Get Dynamic value
            return DateTime.Now;
        }
    }
}
```

حال، برای بررسی اینکه آیا مقادیر Fixed Value و Dynamic Value طبق انتظار کار می‌کنند، متد Main کلاس Program را به صورت زیر تغییر دهید. در اینجا، ما مقادیر CreatedOn و CreatedBy را در شیء منبع ذخیره نمی‌کنیم، اما در حالی که برنامه را اجرا می‌کنید، مقادیر Fixed و Dynamic را که با استفاده از AutoMapper برای ویژگی‌های CreatedOn و CreatedBy شیء مقصد تنظیم کرده‌ایم، مشاهده خواهید کرد.

```csharp
using System;

namespace AutoMapperDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Initialize AutoMapper
            var mapper = MapperConfig.InitializeAutomapper();

            PermanentAddress permAddress = new PermanentAddress()
            {
                Name = "Pranaya",
                Address = "Mumbai"
            };
            var TempAddress = mapper.Map<PermanentAddress, TemporaryAddress>(permAddress);

            Console.WriteLine("After Mapping Permanent Address");
            // Here CreatedBy and CreatedOn will be empty for Permanent Address
            Console.WriteLine($"Name: {permAddress.Name}, Address: {permAddress.Address}, CreatedBy: {permAddress.CreatedBy}, CreatedOn: {permAddress.CreatedOn}");

            Console.WriteLine("After Mapping Permanent Address");
            // Here CreatedBy with Fixed Value and CreatedOn with Dynamic Value
            Console.WriteLine($"Name: {TempAddress.Name}, Address: {TempAddress.Address}, CreatedBy: {TempAddress.CreatedBy}, CreatedOn: {TempAddress.CreatedOn}");

            Console.ReadLine();
        }
    }
}
```

وقتی برنامه را اجرا می‌کنید، خروجی زیر را به شما می‌دهد.

##### **جایگزینی تهی در Automapper:**

جایگزینی Null به ما این امکان را می‌دهد که اگر مقدار منبع null باشد، یک مقدار جایگزین برای عضو مقصد ارائه دهیم. این بدان معناست که به جای نگاشت مقدار null از شیء منبع به شیء مقصد، مقداری را که ما ارائه می‌دهیم، نگاشت می‌کند. ما باید از **متد NullSubstitute()** برای جایگزینی مقدار null با استفاده از AutoMapper استفاده کنیم. بیایید با یک مثال نحوه استفاده **از NullSubstitute()** را در AutoMapper درک کنیم. ما قصد داریم با همان کلاس‌های PermanentAddress و TemporaryAddress کار کنیم.

بنابراین، نیاز ما این است که اگر مقدار ویژگی آدرس در شیء منبع تهی (null) باشد، باید NA را در ویژگی آدرس در شیء مقصد ذخیره کنیم. برای این کار، باید از متد NullSubstitute() استفاده کنیم. بنابراین، کلاس MapperConfig را به صورت زیر تغییر دهید تا از متد NullSubstitute() روی ویژگی آدرس استفاده کند.

```csharp
using AutoMapper;
using System;

namespace AutoMapperDemo
{
    public class MapperConfig
    {
        public static IMapper InitializeAutomapper()
        {
            // Configuring AutoMapper
            var config = new MapperConfiguration(cfg =>
            {
                cfg.CreateMap<PermanentAddress, TemporaryAddress>()
                    // Using MapFrom Method to Store Static or Hard-Coded Value in a Destination Property
                    .ForMember(dest => dest.CreatedBy, act => act.MapFrom(src => "System"))

                    // Using MapFrom Method to Store Dynamic Value in a Destination Property
                    // Here, we are calling GetCurrentDateTime method which will return a dynamic value
                    .ForMember(dest => dest.CreatedOn, opt => opt.MapFrom(src => GetCurrentDateTime()))

                    // Storing NA in the destination Address Property, if Source Address is NULL
                    .ForMember(dest => dest.Address, act => act.NullSubstitute("N/A"))

                    .ReverseMap();
            });

            // Creating the Mapper Instance
            var mapper = config.CreateMapper();

            // returning the Mapper Instance
            return mapper;
        }

        // Method to return Dynamic Value
        public static DateTime GetCurrentDateTime()
        {
            // Write the Logic to Get Dynamic value
            return DateTime.Now;
        }
    }
}
```

در مرحله بعد، متد Main از کلاس Program را به صورت زیر تغییر دهید. در اینجا، مقدار ویژگی Address را NULL قرار می‌دهیم.

```csharp
using System;

namespace AutoMapperDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Initialize AutoMapper
            var mapper = MapperConfig.InitializeAutomapper();

            PermanentAddress permAddress = new PermanentAddress()
            {
                Name = "Pranaya",
                Address = null,
                CreatedBy = "Dot Net Tutorials",
                CreatedOn = DateTime.Now
            };
            var TempAddress = mapper.Map<PermanentAddress, TemporaryAddress>(permAddress);

            Console.WriteLine("After Mapping Permanent Address");
            // Here CreatedBy and CreatedOn will be empty for Permanent Address
            Console.WriteLine($"Name: {permAddress.Name}, Address: {permAddress.Address}, CreatedBy: {permAddress.CreatedBy}, CreatedOn: {permAddress.CreatedOn}");

            Console.WriteLine("After Mapping Permanent Address");
            // Here CreatedBy with Fixed Value and CreatedOn with Dynamic Value
            Console.WriteLine($"Name: {TempAddress.Name}, Address: {TempAddress.Address}, CreatedBy: {TempAddress.CreatedBy}, CreatedOn: {TempAddress.CreatedOn}");

            Console.ReadLine();
        }
    }
}
```

وقتی برنامه را اجرا می‌کنیم، خروجی زیر را به ما می‌دهد. در اینجا، می‌توانید ببینید که در شیء منبع، مقدار آدرس (Address) به صورت NULL چاپ می‌شود (در اینجا نمایش داده نمی‌شود)، اما در ویژگی آدرس مقصد، مقدار به صورت NA چاپ می‌شود.
