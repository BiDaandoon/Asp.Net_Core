
## **زنجیره‌سازی وظایف با استفاده از وظایف ادامه‌دار در سی‌شارپ**

در این مقاله، قصد دارم در مورد **زنجیره‌سازی وظایف با استفاده از وظایف ادامه‌دار در سی‌شارپ** به همراه مثال صحبت کنم. لطفاً مقاله قبلی ما را که در آن در مورد برنامه‌نویسی ناهمزمان مبتنی بر وظیفه در سی‌شارپ به همراه مثال بحث کردیم، مطالعه کنید.

هنگام کار با برنامه‌نویسی ناهمزمان، فراخوانی یک عملیات ناهمزمان از عملیات ناهمزمان دیگر و ارسال داده‌ها پس از اتمام اجرای آن بسیار رایج است. به این کار تداوم می‌گویند و در رویکرد سنتی، این کار با استفاده از روش فراخوانی برگشتی انجام می‌شد که درک آن کمی دشوار است.

اما با معرفی کتابخانه موازی وظایف (TPL)، همین قابلیت را می‌توان به راحتی با استفاده از وظایف ادامه‌دار (continuation tasks) به دست آورد. به عبارت ساده، می‌توانیم یک وظیفه ادامه‌دار را به عنوان یک وظیفه ناهمزمان تعریف کنیم که قرار است توسط وظیفه دیگری (که به عنوان مقدم شناخته می‌شود) فراخوانی شود.

##### **ایجاد یک ادامه برای یک مقدم واحد**

در سی شارپ، می‌توانید با فراخوانی متد ContinueWith که قرار است پس از اتمام اجرای تابع پیشینش اجرا شود، یک ادامه ایجاد کنید.

در مثال زیر، وظیفه مقدم یعنی task1 یک مقدار صحیح برمی‌گرداند. وقتی اجرای آن کامل شد، آن مقدار را به وظیفه ادامه‌دهنده ارسال می‌کند و آن وظیفه ادامه‌دهنده برخی عملیات را انجام می‌دهد و نتیجه را به صورت یک رشته برمی‌گرداند.

```csharp
using System;
using System.Threading.Tasks;

namespace TaskBasedAsynchronousProgramming
{
    class Program
    {
        static void Main(string[] args)
        {
            Task<string> task1 = Task.Run(() =>
            {
                return 12;
            }).ContinueWith((antecedent) =>
            {
                return $"The Square of {antecedent.Result} is: {antecedent.Result * antecedent.Result}";
            });
            Console.WriteLine(task1.Result);

            Console.ReadKey();
        }
    }
}
```

##### **برنامه‌ریزی وظایف مختلف ادامه‌دار**

متد ContinueWith نسخه‌های overload شده‌ای دارد که می‌توانید از آن‌ها برای پیکربندی گزینه‌های متعدد هنگام اجرای ادامه استفاده کنید. به این ترتیب، می‌توانید متدهای ادامه‌ی مختلفی را اضافه کنید که هنگام وقوع یک استثنا، لغو شدن Task یا اتمام موفقیت‌آمیز Task اجرا می‌شوند. برای درک این موضوع، مثالی را بررسی می‌کنیم.

```csharp
using System;
using System.Threading.Tasks;

namespace TaskBasedAsynchronousProgramming
{
    class Program
    {
        static void Main(string[] args)
        {
            Task<int> task = Task.Run(() =>
            {
                return 10;
            });

            task.ContinueWith((i) =>
            {
                Console.WriteLine("Task Canceled");
            }, TaskContinuationOptions.OnlyOnCanceled);

            task.ContinueWith((i) =>
            {
                Console.WriteLine("Task Faulted");
            }, TaskContinuationOptions.OnlyOnFaulted);

            var completedTask = task.ContinueWith((i) =>
            {
                Console.WriteLine("Task Completed");
            }, TaskContinuationOptions.OnlyOnRanToCompletion);

            completedTask.Wait();

            Console.ReadKey();
        }
    }
}
```
