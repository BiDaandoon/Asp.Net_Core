
## **نحوه لغو یک وظیفه غیرقابل لغو در سی شارپ**

در این مقاله، قصد دارم **نحوه** **لغو یک وظیفه غیرقابل لغو در سی شارپ با استفاده از TaskCompletionSource را** با مثال‌هایی بررسی کنم. لطفاً مقاله قبلی ما را که در آن ValueTask را در سی شارپ با مثال‌هایی بررسی کردیم، مطالعه کنید.

##### **لغو وظایف غیرقابل لغو با TaskCompletionSource در سی شارپ**

ما قصد داریم الگویی را ببینیم که از طریق آن می‌توانیم هر وظیفه غیرقابل لغو را به روشی ساده لغو کنیم. وقتی در مورد وظایف غیرقابل لغو صحبت می‌کنیم، منظورمان متدهای ناهمزمانی است که توکن لغو دریافت نمی‌کنند و بنابراین نمی‌توانیم با استفاده از توکن آن را لغو کنیم، مگر اینکه منطق سفارشی برای دستیابی به آن بنویسیم. کاری که ما انجام خواهیم داد این است که از TaskCompletionSource برای ایجاد یک وظیفه ساده استفاده خواهیم کرد که می‌توانیم آن را با یک توکن لغو کنیم. این زمانی مفید است که نمی‌خواهیم یک مهلت زمانی تعیین کنیم، بلکه می‌خواهیم وظیفه‌ای داشته باشیم که هیچ کاری انجام ندهد، اما بتوانیم آن را لغو کنیم.

##### **مثالی برای درک نحوه لغو وظایف غیرقابل لغو در سی شارپ:**

بیایید با یک مثال نحوه لغو وظایف غیرقابل لغو در سی شارپ با استفاده از TaskCompletionSource را درک کنیم. کاری که قرار است انجام دهیم این است که یک کلاس جدید ایجاد می‌کنیم که یک کلاس استاتیک خواهد بود زیرا یک متد افزونه روی آن خواهیم داشت. بنابراین، من یک فایل کلاس با نام TaskExtensionMethods.cs ایجاد می‌کنم و سپس کد زیر را در آن کپی و جایگذاری می‌کنم.

```csharp
using System;
using System.Threading.Tasks;
using System.Threading;

namespace AsynchronousProgramming
{
    public static class TaskExtensionMethods
    {
        public static async Task<T> WithCancellation<T>(this Task<T> task, CancellationToken cancellationToken)
        {
            var TCS = new TaskCompletionSource<object>(TaskCreationOptions.RunContinuationsAsynchronously);

            using (cancellationToken.Register(state =>
            {
                ((TaskCompletionSource<object>)state).TrySetResult(null);
            }, TCS))
            {
                var resultTask = await Task.WhenAny(task, TCS.Task);
                if (resultTask == TCS.Task)
                {
                    throw new OperationCanceledException(cancellationToken);
                }

                return await task;
            }
        }
    }
}
```

در اینجا، ما کلاس را public و static می‌کنیم زیرا قرار است متد Extension را اضافه کنیم. نام متد WithCancellation به نام Cancellation مربوط به Stream ناهمگام اشاره دارد که در مقاله بعدی به آن خواهیم پرداخت.

پارامتر اول متد WithCancellation به نام کلاسی که این متد الحاقی به آن تعلق دارد اشاره دارد. در اینجا، این کلاس Task\<T> است. پارامتر دوم، پارامتر معمولی است و ما باید این پارامتر را هنگام فراخوانی این متد ارسال کنیم و در اینجا یک توکن لغو است.

همانطور که گفتیم، به یک TaskCompletionSource نیاز داریم. بنابراین، باید یک نمونه از TaskCompletionSource ایجاد کنیم.

حالا، چیزی به نام توکن لغو وجود دارد و یک متد Register دارد که قرار است وقتی توکن لغو می‌شود، متدی را اجرا کند. بنابراین، می‌توانیم از این‌ها برای اجرای یک بخش سفارشی از عملکرد، وقتی توکن لغو لغو می‌شود، استفاده کنیم. با این کار، الگوی خود را برای لغو یک وظیفه غیرقابل لغو در C# پیاده‌سازی کرده‌ایم. حالا، بیایید از این الگو استفاده کنیم.

##### **مثال بدون استفاده از الگوی توکن لغو ما**

```csharp
using System;
using System.Threading.Tasks;
using System.Threading;

namespace AsynchronousProgramming
{
    class Program
    {
        static CancellationTokenSource cancellationTokenSource;
        static void Main(string[] args)
        {
            SomeMethod();
            Console.ReadKey();
        }

        public static async void SomeMethod()
        {
            cancellationTokenSource = new CancellationTokenSource();

            try
            {
                var result = await Task.Run(async () =>
                 {
                     await Task.Delay(TimeSpan.FromSeconds(5));
                     Console.WriteLine("Operation was Successful");
                     return 7;
                 }).WithCancellation(cancellationTokenSource.Token);
            }
            catch (Exception ex)
            {
                Console.WriteLine(ex.Message);
            }
            finally
            {
                cancellationTokenSource.Dispose();
                cancellationTokenSource = null;
            }
        }
    }
}
```

##### **مثالی از الگوی توکن لغو ما**

```csharp
using System;
using System.Threading.Tasks;
using System.Threading;

namespace AsynchronousProgramming
{
    class Program
    {
        static CancellationTokenSource cancellationTokenSource;
        static void Main(string[] args)
        {
            SomeMethod();
            CancelToken();
            Console.ReadKey();
        }

        public static async void SomeMethod()
        {
            cancellationTokenSource = new CancellationTokenSource();

            try
            {
                var result = await Task.Run(async () =>
                 {
                     await Task.Delay(TimeSpan.FromSeconds(5));
                     Console.WriteLine("Operation was Successful");
                     return 7;
                 }).WithCancellation(cancellationTokenSource.Token);
            }
            catch (Exception ex)
            {
                Console.WriteLine(ex.Message);
            }
            finally
            {
                cancellationTokenSource.Dispose();
                cancellationTokenSource = null;
            }
        }

        public static void CancelToken()
        {
            cancellationTokenSource?.Cancel();
        }
    }
}
```
