# مقدمه و راه اندازی

در این بخش مطالب زیر را می‌خوانید:

- کامپیوتر چگونه کار می‌کند؟
- مقدمه‌ای بر زبان‌های برنامه‌نویسی
- نحوه کار برنامه‌های کامپیوتری
- انواع مختلف کاربردها
- روش‌شناسی‌های برنامه‌نویسی
- الگوریتم، شبه‌کد، برنامه‌ها و فلوچارت‌ها
- مقدمه‌ای بر چارچوب دات‌نت
- معماری و اجزای چارچوب دات نت
- مقدمه‌ای بر زبان برنامه‌نویسی سی‌شارپ
- نقشه راه توسعه‌دهندگان دات‌نت برای سال 2025
- بهترین روش‌های استاندارد کدنویسی
